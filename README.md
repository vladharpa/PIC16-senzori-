Un mic proiect didactic de monitorizare a mediului ambiant, realizat pentru a exersa bazele programării embedded.

Sistemul citește date de la senzori analogici (temp/umiditate/lumină) folosind ADC-ul microcontrolerului și afișează informațiile pe un LCD tip 16x2.

Ce am învățat din acest proiect:

Implementarea unui driver pentru LCD folosind comunicație paralelă (bare-metal C).

Gestionarea conversiei semnalelor analogice către format digital prin registre (ADC).

Utilizarea simulării în Proteus+ MPLABX + KICAD pentru validarea schemei înainte de implementarea fizică.

Este un exercițiu simplu, dar care m-a ajutat să înțeleg mai bine „mașinăria” din spatele unui sistem digital.
